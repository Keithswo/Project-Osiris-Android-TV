# Project Osiris Android TV v1.4 — Windows alignment preview

Based on the supplied Android TV source and the Windows v2.3.9 design reference.

Implemented: Windows-order left navigation; yellow active outline and white focus; Guide preview and timeline in the same main area; optional Categories panel toggled from Guide or the sidebar; remote-focusable Guide channel rows; Settings explicit keyboard editing (OK to edit, IME Done to finish); Settings remote focus navigation and scrolling to Save.

**Not implemented in this preview:** Windows-equivalent DVR buffering, FFmpeg transcoding, full 4-screen reliability, and pixel-identical Windows interface. The Android native player and IPTV connection logic are preserved. The Android APK has not been compiled or device-tested.

Install using the existing GitHub Actions Android APK workflow. Please test navigation and Settings first.
